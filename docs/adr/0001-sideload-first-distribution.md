# Sideload-first distribution

Mindverse distributes as a sideloaded APK (GitHub Releases with in-app update check) with F-Droid as the second channel; the Play Store is a deliberate non-target for v1. The app leans on permission-heavy Android surfaces (AccessibilityService, NotificationListenerService, SYSTEM_ALERT_WINDOW) whose Play-policy review burden is disproportionate for a solo developer, and sideloading keeps release cadence independent of review. Consequences: the volume-chord accessibility trigger and edge handle ship in v1 behind explicit in-app opt-in (see ADR-0004), F-Droid requires the app to be fully FOSS with reproducible builds (closed-blob deps like ML Kit are confined to a `play` Gradle flavor), and organic discovery is weakened by design in exchange for iteration speed and user trust.
